# Install Switchyard

On a Kindle started with Primitive Launcher, open **Store**, find **Switchyard**, and tap **Get**. Launch the game from your app grid.

For local testing on an ARMHF Kindle, verify the SHA-256 of the release archive and extract it. Copy the `switchyard/` folder to the Kindle drive root and `documents/Switchyard.sh` into the existing Kindle `documents/` folder. Eject the drive and open **Switchyard** in Launcher.

The game saves progress in `switchyard/switchyard.json`. Back up that file before removing the game folder manually.
